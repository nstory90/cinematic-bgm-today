# Cinematic BGM Today

오늘의 기분·날씨·일정으로, 하루를 영화처럼 만드는 아침·점심·저녁 BGM.

**바로 열기:** https://nstory90.github.io/cinematic-bgm-today/

## 이렇게 써요
1. **지금 기분** — 📷 카메라로 표정을 읽어 7가지 기분을 실시간 %로 보여 주거나, 카드에서 직접 고릅니다.
2. **오늘 일정** — 회의·보고·야근 등 해당하는 일정을 고릅니다. 바쁠수록 템포가 달라져요.
3. **원하는 분위기** — 저녁에 도착하고 싶은 기분을 고르면, 오늘의 영화와 장면별 BGM이 나옵니다.

날씨는 현재 위치로, 시간대는 앱을 연 시각으로 자동으로 정해집니다.

## 어떻게 동작하나요
- **판단은 코드가:** 표정 → 기분 %, 기분 → 장르·BPM·색, 일정 강도 보정, 기분 전환 흐름은 모두 규칙으로 정해져 같은 입력에 같은 결과가 나옵니다. (`node selfTest.js` 로 68개 검사)
- **표정 인식은 브라우저 안에서:** 카메라 영상은 저장하거나 밖으로 보내지 않습니다. 여러 명이 보이면 카메라에 가장 가까운 1명만 읽어요.
- **감성 문구:** AI 키가 있으면 Claude 또는 OpenAI가 영화 제목·카피를 쓰고, 없으면 미리 준비한 예시 문구로 동작합니다. 이 공개 페이지에는 키가 없으므로 예시 문구가 나옵니다.
- **음악:** Tone.js가 카드의 BPM·장르·분위기로 직접 연주합니다. 💎 모드를 켜면 준비한 곡을 그대로 들려줍니다.

## 직접 실행하려면
파일을 내려받아 `index.html`을 브라우저(Chrome·Edge)로 열면 됩니다. AI 문구를 쓰려면 `bgm.config.example.js`를 `bgm.config.js`로 복사해 키를 넣으세요 (`bgm.config.js`는 저장소에 올리지 않습니다).
